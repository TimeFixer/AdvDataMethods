# MLOps Data Pipeline: Анализ и прогнозирование стоимости бриллиантов (Dataset Diamonds)

Практический проект по полному циклу машинного обучения (MLOps), посвященный разработке воспроизводимого конвейера обработки данных, автоматической инженерии признаков и развертыванию регрессионной модели.

## 🛠 Технологический стек

* **Язык**: Python
* **Инструменты ML**: Scikit-Learn (Pipeline, ColumnTransformer, GridSearchCV, RandomForestRegressor)
* **Инженерия признаков**: Featuretools (Deep Feature Synthesis)
* **Контроль версий и данных**: Git, DVC (Data Version Control)
* **Среда**: Jupyter Notebook, Pandas, NumPy

---

## 📁 Структура проекта

* `data/` — директория для хранения сырых и обработанных данных (версионируется через DVC)
* `notebooks/` — интерактивные блокноты с исследованиями и пайплайнами
* `src/` — модульный исходный код проекта (кастомные трансформеры, скрипты предобработки)
* `models/` — сохраненные сериализованные модели (`.joblib`)
* `reports/` — подробные технические отчеты и визуализации
